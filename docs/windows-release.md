Windows Intel/AMD x64 portable preview. The ZIP contains the self-contained executable, Whisper engine, speech model and runtime libraries. Extract it into a writable folder and run LocalMeetingNotes.exe. No existing recordings are included.

This build passed compilation and storage/recovery checks. The Windows capture/transcription path was also checked locally during development; audio-device behavior on another computer should be checked with a short recording. The executable is unsigned. See the repository README for storage, deletion and recovery limits.
